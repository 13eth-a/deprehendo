# Uiverse.io elements

Uiverse elements are plain HTML and CSS, so most of them live in
`styles/vendor.css` as classes rather than as components here. Every one is
MIT licensed (see `LICENSE`) and credited in the stylesheet next to its rules.

| deprehendo class | Uiverse element | Used for |
| --- | --- | --- |
| `.uv-button` | `wet-ape-7` by danilppzz | Secondary buttons |
| `.uv-button--primary` | `hard-panther-41` by VassoD, recolored | Primary buttons |
| `.uv-input` | `tiny-robin-35` by danilppzz | Text inputs and selects |
| `.uv-field` | `polite-dingo-63` by saidbl1 | Labelled form fields |
| `.uv-progress` | `yellow-panther-46` by gagan-gv | "Analysis in progress" |
| `.uv-spinner` | `massive-newt-28` by mrhyddenn | Pending buttons |

`Loaders.tsx` wraps the two loaders' markup.
